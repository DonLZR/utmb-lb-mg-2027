🔐 Changer le code d’accès

L’empreinte est calculée uniquement dans ce navigateur. Le code saisi n’est envoyé nulle part.

—

  1. Ouvre ton fichier personnel cles.js.
  2. Remplace uniquement la valeur de accessCodeHash par l’empreinte copiée.
  3. Publie le nouveau cles.js sur GitHub, puis teste le site en navigation privée.

Les appareils déjà autorisés reverront automatiquement l’écran d’accès, car l’empreinte aura changé.
